
# My-Masala-Box Website – HTML, CSS, and Bootstrap Project

This project is a fully responsive Spices Website built using HTML, CSS, and Bootstrap 5. It showcases various spice products with a clean layout, structured sections, and modern UI components.

---

## Features

### 1. Responsive Navigation Bar

* Home
* About
* Products
* Contact
* Sign In button

### 2. Home Section

* Title and tagline
* Email input field
* "Get Started" button

### 3. About Section

* Two-column layout
* About image
* Detailed description

### 4. Products Section

* Grid-based layout using Bootstrap
* Nine product cards
* Image, title, and button for each product

### 5. Contact Section

* Name, email, and message form
* Contact image
* Styled submit button

### 6. Footer

* Contact details
* Copyright information
